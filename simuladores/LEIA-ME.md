# Pasta dos simuladores

Todo arquivo `.html` colocado aqui aparece sozinho na aba **Aulas e simuladores** do site.
O nome do arquivo vira o nome no menu (os `_` viram espaços).

Atenção: este repositório é público. Um arquivo colocado aqui pode ser lido por
qualquer pessoa no GitHub, e todo HTML que roda no navegador pode ter o código
visto pelo usuário. Não há como "fechar" totalmente um HTML; dá apenas para
dificultar a leitura (minificação/ofuscação do JavaScript).
